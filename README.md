# UniGuide — University Guide for Pakistan

A web app to help Pakistani students find, compare, and apply to universities — all in one place.

**Live Demo:** https://university-guide-mu2t.vercel.app/

## Features

- **Program Search** — search programs across 12 top Pakistani universities
- **University Info** — view programs, fees, address, and rankings per university
- **Admission Deadlines** — track current and upcoming admission deadlines
- **Aggregate Calculator** — calculate your admission aggregate using a simple unified formula
- **Compare Universities** — side-by-side comparison of fees, rankings, and entry requirements
- **Scholarships** — explore financial aid and scholarship options per university
- **AI Chatbot** — ask anything about admissions, programs, and universities

## Tech Stack
- HTML, CSS, JavaScript
- Python, BeautifulSoup, Selenium (web scraping)
- Vercel (deployment)

## Data
Scraped from 12 top Pakistani universities including deadlines, fees, addresses, rankings, scholarships, and programs. Searchable by program name or university.
